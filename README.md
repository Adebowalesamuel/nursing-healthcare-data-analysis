# Nursing & Healthcare Data Analysis

A beginner-friendly healthcare data analysis project that combines nursing knowledge with Python and data analysis skills.

## Project Overview

This project uses a small sample healthcare dataset to explore patient visits, waiting times, departments, visit types, and satisfaction scores.

The goal is to demonstrate basic data handling and analysis using Python while applying a healthcare perspective.

## Dataset

The sample dataset contains 10 patient visit records with the following variables:

- Age
- Gender
- Department
- Visit type
- Waiting time in minutes
- Satisfaction score

The dataset is located in:

`data/healthcare_sample.csv`

> **Note:** This is a fictional sample dataset created for learning and portfolio purposes. It contains no real patient information.

## Analysis

The Python script calculates:

- Number of patient records
- Average waiting time
- Average satisfaction score
- Longest waiting time
- Shortest waiting time
- Department-level visit counts
- Average waiting time by department
- Average satisfaction by department

The analysis script is located in:

`analysis/healthcare_analysis.py`
